Host cards

Mac

Purpose: Author dotfiles, Cursor/Pi, Paseo orchestration.

Dispatch: paseo --host ssh://monsterbro …

MCP: mcporter full catalog; dockhand on-demand.

MonsterBro

Win: monsterbro / .250 — RDP :3389.

WSL: monsterbro-wsl / .255 — SSH :27789, Paseo daemon.

SSH alias: monsterbro → WSL (same as monsterbro-wsl).

Caveat: Sometimes off — ping monsterbro-wsl before propagate.

LinuxBro

HW: NUC i5-8259U, 16 GB, ~31 containers.

MCP: dockhand :8092

Fit: Light chores; RAM tight under load.

SuperBro

Role: Janitor, graphiti, pi-peer Redis.

MCP: dockhand :8080, graphiti :8000

Vault: rbw → vault.superbro.dk

Quick commands

# SSH hardening + known_hosts
bash ~/dotfiles/scripts/install/ssh-superbro.sh

# List agents on MonsterBro
paseo --host ssh://monsterbro ls

# Dispatch work
paseo --host ssh://monsterbro run --provider codex/gpt-5.4 \
  --cwd ~/dotfiles "Run ./scripts/doctor.sh; failures only"

# Propagate dotfiles (MonsterBro WSL, if online)
ping -c1 monsterbro-wsl && ssh monsterbro \
  'git -C ~/dotfiles pull && DOTFILES_NONINTERACTIVE=1 DOTFILES_WORKFLOWS=wsl \
   ~/dotfiles/bootstrap.sh --only=symlinks,opencode'

MonsterBro bootstrap

  1. Windows: AC never sleep, Tailscale (monsterbro/.250), RDP :3389, OpenSSH :27789 → WSL
  2. WSL Tailscale: monsterbro-wsl / .255
  3. WSL: systemd=true in /etc/wsl.conf
  4. Clone dotfiles, PROFILE=wsl, bootstrap
  5. npm i -g paseo, set password, create projects
  6. systemd user unit for daemon autostart
  7. Verify from Mac via ssh://monsterbro
