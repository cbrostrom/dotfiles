# brain

Dispatch table for `.brain` subcommands. All writes are atomic (write to `.tmp`, then `mv`). Default slug = git repo basename; fall back to PWD basename.

## Vault Path

| Platform | Path |
|---|---|
| macOS | `~/Vaults/Brain` |
| WSL | `/mnt/c/Users/christian/Obsidian/Brain` |

Use `$VAULT` as shorthand. Detect: `uname` = Darwin → macOS.

## Slug Resolution

1. Explicit slug arg if provided (e.g. `.brain homelab "text"`)
2. Active plan `repo:` frontmatter (if a plan is loaded)
3. Loaded brain slug (from session context)
4. `git rev-parse --show-toplevel | xargs basename`
5. `basename $PWD`

Multiple plausible candidates that differ → ask via `AskUserQuestion` before writing.

## Directory Layout

```
$VAULT/Brains/<slug>/
  INDEX.md       — auto-generated file map (read-only; regenerated by cheap-optimise)
  current.md     — facts true right now
  gotchas.md     — known traps (grep-on-demand)
  next.md        — actionable items; [done: YYYY-MM-DD] markers
  history/
    YYYY-MM-DD-HHMM.md   — session snapshots
  archive/
    YYYY-MM.md   — rolled-up history >30 days old
```

## Subcommand Dispatch

### `.brain` (no args)

Scan the current conversation. Draft a summary of:
- Key decisions made this session
- Findings / discoveries
- Changes completed
- Open blockers

Append to `$VAULT/Brains/<slug>/history/YYYY-MM-DD-HHMM.md` (create if not exists, using current timestamp). Use atomic write.

Output before writing: `> 🧠 **Brain → history** \`YYYY-MM-DD-HHMM.md\``
Output after: `> ✅ **Saved**`

### `.brain <text>` (free-form text, no recognized subcommand)

Append `<text>` as a timestamped block to `history/YYYY-MM-DD-HHMM.md` (current session file). Frictionless dump.

Format:
```
## <YYYY-MM-DD HH:MM> — note

<text>
```

### `.brain current <text>`

Merge `<text>` into `current.md`. If text is clearly an update to an existing section, replace that section. Otherwise append a new section. No destructive overwrites — existing facts survive unless explicitly contradicted.

Use atomic write. Output: `> 🧠 **Brain → current.md** updated`

### `.brain gotcha <text>`

Append a new bullet to `gotchas.md`:

```markdown

- **<short label>**: <text>
```

Where `<short label>` = first 4–6 words of `<text>` bolded. Use atomic write.

### `.brain next <text>`

Append a new bullet to `next.md`:

```
- <text>
```

### `.brain done <substring>`

Find the line in `next.md` that contains `<substring>`. Stamp it with `[done: YYYY-MM-DD]` at end of line. Atomic write. If multiple matches, show them and ask which to stamp.

### `.brain optimise [slug]`

Invoke the `brain/optimise` subskill. If `[slug]` not provided, use resolved slug.

### `.brain migrate <slug>`

Run `~/dotfiles/scripts/brain-migrate.sh <slug>`. Confirm destination doesn't exist before proceeding.

### `.brain show [slug]`

Print what the next SessionStart would load:
1. Read `INDEX.md`
2. Read `current.md`
3. Read `next.md` (lines without `[done:]`)

Format as the brain-load header block so user can preview the payload.

## Output Protocol

- Before writing: announce target file in one line
- After writing: `> ✅ **Saved**`
- Never read back the file after writing (trust atomic write)
- Never output full file content unless user asks to `.brain show`
